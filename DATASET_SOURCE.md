# Dataset Source

The `student_data.csv` file is the mathematics-course data from the UCI Student Performance dataset:

Cortez, P. (2008). Student Performance [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5TG7T

The dataset is licensed under CC BY 4.0: https://creativecommons.org/licenses/by/4.0/

## Lab 4 Sample Data

`student_performance_dataset.csv` is a small synthetic sample created to exercise the missing-value handling and encoding steps in `lab4.py`. Its values are illustrative and are not an official student dataset.
